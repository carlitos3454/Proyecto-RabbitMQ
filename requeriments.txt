# Proyecto RabbitMQ - Arquitectura de Software

Sistema de procesamiento asíncrono para facturación utilizando RabbitMQ y Python.

## Estructura del Proyecto
- `productor.py`: Envía órdenes de facturación a la cola.
- `consumidor.py`: Procesa las órdenes y genera PDFs simulados.
- `requirements.txt`: Dependencias del proyecto.

## Requisitos
- Tener RabbitMQ instalado y corriendo (por ejemplo, vía Docker).
- Python 3.x instalado.

## Instalación
1. Clonar el repositorio:
   `git clone https://github.com/carlitos3454/Proyecto-RabbitMQ.git`
2. Instalar dependencias:
   `pip install -r requirements.txt`

## Ejecución
1. Iniciar el consumidor:
   `python consumidor.py`
2. En otra terminal, ejecutar el productor:
   `python productor.py`
